사람 검출

사용할 검출 기능은 Live Search의 [분석 시작] 버튼 위에서 선택합니다. 이 화면에서는 검출 빈도와 기준을 설정합니다.

1~240 FPS. 모든 프레임 검사를 체크하면 원본 영상의 모든 프레임에서 검출합니다.
0~1. 높이면 신뢰도가 높은 사람만 검출합니다. 저장하면 실행 중인 Live Search의 다음 검출부터 적용됩니다. 새 추적 시작 기준 {{ settings.features.person_track_start_threshold | number:'1.2-2' }}는 별도 기준입니다.

얼굴 검출

0.1~240 FPS. 사람 검출 빈도와 독립적으로 적용됩니다. 모든 프레임 검사를 체크하면 FPS 제한을 사용하지 않습니다.
0.10~0.99. 얼굴 검출 테스트와 동일한 검출 기준입니다. Live Search에서 얼굴 검출을 선택한 업로드 영상에 적용됩니다.
8~512 px 정수. 원본 얼굴 영역의 짧은 변을 기준으로 합니다. 얼굴 검출 테스트와 같은 조건이며 각 화면의 값은 별도로 저장됩니다.
1~16명. 여러 사람이 있을 때 대기 순서에 따라 검사합니다.

등록 인물 비교

코사인 유사도 -1~1. 기본값은 0.75입니다. 낮추면 후보가 늘고, 높이면 더 비슷한 얼굴만 후보가 됩니다.

업로드 영상에서 모든 프레임 검사를 선택하면 프레임을 건너뛰지 않고 순서대로 처리합니다. GPU 처리량에 따라 분석이 재생 시간보다 오래 걸릴 수 있습니다. FPS 설정은 원본 영상의 FPS를 넘겨 검출하지 않습니다. RTSP는 지연을 제한하기 위해 수신한 최신 프레임을 우선 처리합니다.

얼굴 검출·비교 방식

  • Live Search에서 얼굴 검출을 선택한 업로드 영상은 사람 검출 여부와 관계없이 전체 화면과 겹치는 분할 영역에서 얼굴을 직접 검사합니다. 검출·최소 크기·얼굴 정렬 조건은 얼굴 검출 테스트와 같습니다. 등록 인물과의 비교에는 아래의 여러 사진 확인 조건을 유지합니다.
  • 업로드 영상의 사람과 얼굴은 각각 검출하며 추적 번호도 별개입니다. 사람 검출 결과가 없어도 얼굴을 검사합니다.
  • RTSP 입력은 사람 검출만 사용하며 얼굴 검출·등록 인물 식별·검색 이벤트 생성을 수행하지 않습니다.
  • 최근 {{ settings.features.sample_window_seconds }}초의 품질 통과 사진을 최대 {{ settings.features.sample_count }}장 사용합니다. 품질에 따른 평균 점수와 최소 {{ settings.features.minimum_samples }}장의 기준 이상 결과로 후보를 판단합니다.
  • 비교점수 기준은 Live Search의 후보 판정·이벤트 저장과 인물 관리의 사진 시험 비교에 적용됩니다. 이미 저장된 검색 이벤트는 유지됩니다.
