업로드한 MP4에 적용됩니다. 체크를 끄면 사람 검출을 거치지 않고 전체 화면에서 얼굴을 찾은 후 등록 인물과 비교합니다. 모드를 바꾸면 업로드 영상의 추적 세션을 새로 시작합니다. RTSP 입력의 처리 방식은 변경되지 않습니다.

0.10~0.99. 얼굴 검출 테스트와 동일한 검출 기준입니다. 사람 검출을 끈 업로드 영상에 적용됩니다.
8~512 px 정수. 원본 얼굴 영역의 짧은 변을 기준으로 합니다. 얼굴 검출 테스트와 같은 조건이며 각 화면의 값은 별도로 저장됩니다.
0~1. 높이면 신뢰도가 높은 사람만 검출합니다. 저장하면 실행 중인 Live Search의 다음 검출부터 적용됩니다. 새 추적 시작 기준 {{ settings.features.person_track_start_threshold | number:'1.2-2' }}는 별도 기준입니다.
1~15 FPS. 높이면 움직임을 더 자주 확인합니다.
0.2~10초. 작을수록 인물별 얼굴 검사 기회가 늘어납니다.
1~16명. 여러 사람이 있을 때 대기 순서에 따라 검사합니다.
코사인 유사도 -1~1. 기본값은 0.75입니다. 낮추면 후보가 늘고, 높이면 더 비슷한 얼굴만 후보가 됩니다.

얼굴 검출·비교 방식

  • 사람 검출을 끈 업로드 영상은 전체 화면과 겹치는 분할 영역에서 얼굴을 직접 검사합니다. 검출·최소 크기·얼굴 정렬 조건은 얼굴 검출 테스트와 같습니다. 등록 인물과의 비교에는 아래의 여러 사진 확인 조건을 유지합니다.
  • 사람 검출을 사용하는 경우 머리 영역을 먼저 검사하고 필요한 경우 사람 전체 영역으로 재검사합니다.
  • 얼굴 미검출·작은 얼굴 등에 한해 {{ settings.features.retry_detector_size }}px 입력으로 재검사합니다.
