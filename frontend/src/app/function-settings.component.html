Person Detection

Choose detection features above Start Analysis in Live Detector. Set detection rates and thresholds here.

1~240 FPS. Select every-frame processing to detect in every frame of the source video.
0~1. Higher values detect only high-confidence people. Saving applies the value to active Live Detector from the next detection. The new-track threshold {{ settings.features.person_track_start_threshold | number:'1.2-2' }} uses a separate threshold.

Face Detection

0.1~240 FPS. Applied independently of the person detection rate. Every-frame processing disables the FPS limit.
0.10~0.99. Uses the same detection threshold as Face Detection Test. Applies to streams and uploaded videos with face detection enabled in Live Detector.
8~512 px integer. Uses the shorter side of the original face region. Criteria match Face Detection Test, but each page saves its own values.
1~16 people. When several people are present, analysis follows the waiting order.

Registered Person Comparison

Cosine similarity from -1 to 1. Default: 0.75. Lower values produce more candidates; higher values require a closer match.

When every-frame processing is selected for uploaded videos, frames are processed sequentially without skipping. GPU throughput may cause analysis to take longer than the video duration. The detection rate cannot exceed the source video FPS. RTSP prioritizes the latest received frame to limit latency.
